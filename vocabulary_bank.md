# Active Vocabulary Bank

The objective of this file is to develop vocabulary that the student can actively use in conversation.

Do not store large lists of isolated words.

Prefer:

- collocations
- chunks
- sentence patterns
- phrasal verbs
- executive expressions

- address structural issues

## Activation Rule

Vocabulary becomes active only after the student successfully uses it naturally in several different conversations.
